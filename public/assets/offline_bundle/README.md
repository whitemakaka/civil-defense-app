# Offline Bundle

This folder should contain the offline search bundle generated by `data_helpers`.

## Required Files

```
offline_bundle/
├── manifest.json           # Bundle metadata (schema_version, model_id, dim, count)
├── records_meta.jsonl      # One JSON object per line (id, country, lang, title, content, keywords, embedding_idx, ...)
├── keyword_index.json      # Inverted index for keyword search
├── embeddings.int8.bin     # INT8 quantized embeddings (raw bytes, dim × count)
├── embeddings.scale.f16.npy # Float16 scale per vector (NPY format)
└── model/
    ├── model.int8.onnx     # Quantized ONNX embedding model
    ├── tokenizer.model     # SentencePiece tokenizer binary
    └── special_tokens.json # Token IDs (bos, eos, pad, unk)
```

## How to Generate

Use the `data_helpers` pipeline:

```bash
cd data_helpers

# 1. Prepare your source data in records_data/
#    Format: JSONL with fields: id, country, lang, title, content, keywords, ...

# 2. Run the bundle generator
python build_bundle.py --input records_data/your_records.jsonl --output ../app_final/android/app/src/main/assets/offline_bundle/

# 3. Copy to public/assets as well (for build script)
cp -r ../app_final/android/app/src/main/assets/offline_bundle/* ../app_final/public/assets/offline_bundle/
```

## Build Integration

After placing files here, run:

```powershell
.\build-release.ps1
```

This will copy the bundle and build the release APK.

## Schema Version

Current schema: **v4a**

- Embeddings: INT8 + float16 scale (per-vector dequantization)
- Tokenization: SentencePiece (outside ONNX graph)
- Model: ONNX Runtime (no ORT Extensions)

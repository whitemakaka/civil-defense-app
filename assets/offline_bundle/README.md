# Offline Bundle

This folder should contain the offline search bundle generated by `data_helpers`.

## Required Files

```
offline_bundle/
├── manifest.json           # Bundle metadata (schema_version, model_id, dim, count)
├── records_meta.jsonl      # Record metadata (one JSON per line)
├── keyword_index.json      # Inverted index for keyword search
├── embeddings.int8.bin     # INT8 quantized embeddings (raw bytes)
├── embeddings.scale.f16.npy # Float16 scale per vector (NPY format)
└── model/
    ├── model.int8.onnx     # Quantized ONNX embedding model
    ├── tokenizer.model     # SentencePiece tokenizer (binary)
    └── special_tokens.json # Token IDs (bos, eos, pad, unk)
```

## How to Generate

1. Prepare your source data in `data_helpers/records_data/` (JSONL format)
2. Run the bundle generation script:

```bash
cd data_helpers
python build_bundle.py --output ../app_final/assets/offline_bundle/
```

3. Copy to Android assets before building:

```powershell
.\build-release.ps1
```

Or manually:

```powershell
Copy-Item -Recurse -Force "assets\offline_bundle\*" "android\app\src\main\assets\offline_bundle\"
```

## Notes

- Bundle files are **not included in the repository** (too large for Git)
- Each contributor generates their own bundle from source data
- The app validates bundle compatibility on startup via `manifest.json`
